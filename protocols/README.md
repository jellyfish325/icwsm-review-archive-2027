# Analysis protocols

These files specify the methods used for the released analysis.

- `sentiment_role_protocol.md`: directed-sentiment and discursive-role annotation rules.
- `framing_protocol.md`: generic-frame annotation rules.
- `h3_analysis_record.md`: final exploratory H3 estimator, eligibility rules,
  uncertainty procedure, and interpretation.

All population counts refer to the final release described in `SCHEMA.md` and
enforced by `reproduce.py`.
